facilities.csv - Kaafu Connect data pack
========================================

What it is
----------
One row per hospital or health centre that the trip calculator can route
to. 29 rows, built 23 Oct 2026. It covers Greater Malé, the 9 Kaafu
islands, and the 14 inbound islands in Alif Alif, Alif Dhaalu and Vaavu.

  Type                        Rows  Covers
  hospital (Greater Malé)        6  IGMH, ADK, Senahiya, Hulhumalé Hospital,
                                    Tree Top, Villimalé Hospital
  hospital (atoll)               3  Rasdhoo (AA), Mahibadhoo (ADh),
                                    Felidhoo (V)
  health_centre                 20  Every other island on the list. Rasdhoo,
                                    Mahibadhoo and Felidhoo have no separate
                                    row because their atoll hospital is
                                    their health facility.

The file is UTF-8 with a BOM, so Excel shows é in Malé correctly.


Columns
-------
  facility_id         H01-H09 hospitals, C01-C20 health centres
  name                Facility name. Where the OSM name differs, the OSM
                      name is given in notes.
  type                hospital, health_centre
  level               tertiary (Greater Malé hospitals), regional/atoll,
                      island
  island_key          RTL-style key, e.g. K.Maafushi, ADh.Dhangethi,
                      K.Malé. Join to the islands sheet on this column.
  island              Island name only, e.g. Maafushi
  atoll               K, AA, ADh, V
  lat, lon            Decimal degrees (WGS84 / EPSG:4326)
  access_point        Greater Malé: nearest RTL bus stop.
                      Other islands: "<island_key> harbour".
  access_point_code   RTL bus stop code (Greater Malé only; blank for
                      harbours)
  access_distance_m   Straight-line distance from facility to access
                      point, in metres
  walk_minutes        access_distance_m / 80 (80 m per minute, as set in
                      the prep guide)
  location_quality    exact = mapped building in OSM;
                      estimated = placed at island centre or bus stop
  source              OSM link, or the file and stop the location came from
  notes               Name differences and things to confirm


How it was built
----------------
- Facility locations: OpenStreetMap via the Overpass API, 23 Oct 2026
  (amenity=hospital/clinic/doctors, healthcare=*, building=hospital and
  name searches).
- Greater Malé access points: nearest stop in Team Kandu rtl_bus_stops.csv
  (area = Greater Malé), by straight-line distance.
- Island access points: the harbour point in islands.csv. Gaafaru,
  Guraidhoo and Hangnaameedhoo use real harbours from OSM. The rest come
  from odi_connections.csv, which turned out to be island centres rather
  than harbours (see islands.txt), so their walk_minutes may be off by a
  few minutes.
- Walking distances are straight lines. Real walks are a little longer, but
  on these islands no walk is more than about 7 minutes.
- Built with an AI-assisted script outside the project repo. Only this CSV
  is used. Mention it under "AI-assisted parts" in the README.


To check before relying on it
-----------------------------
1. 8 rows have estimated locations (location_quality = estimated). OSM had
   nothing, so each is placed at the island centre. Islands are under ~1 km
   across, so the error is a few minutes of walking. To fix one, find the
   building in Google Maps or OSM and replace lat/lon.
     Health centres: Gaafaru, Himmafushi, Hangnaameedhoo, Omadhoo,
       Fulidhoo, Keyodhoo, Thinadhoo.
     Villimalé Hospital: placed at the "Villimale Hospital" bus stop
       (code 1313).
2. H01: OSM maps IGMH and "Dharumavantha Hospital" on the same site. They are
   treated as one destination. Confirm whether it is a rename or a separate
   building.
3. H03 Senahiya is a military hospital. Confirm it takes public emergencies;
   if not, drop it as a destination.
4. Names that may be wrong in OSM:
     H07  Rasdhoo "Rasdhoo hospital" assumed to be the AA atoll hospital
     H08  Mahibadhoo "South Ari District Medical Center" assumed to be the
          ADh atoll hospital
     C07  Gulhi "Island Clinic" assumed to be the government health centre
5. Thulusdhoo: a new K. Thulusdhoo Hospital is under construction (OSM way
   1466963363). Good scenario for the "what if" slider.
