ferry_timetable.csv - Kaafu Connect data pack
=============================================

What it is
----------
One row per boat leg between two consecutive project stops of one trip, in
the "one row per departure" layout from BUILD_PLAN 6.1. 794 rows, built
23 Oct 2026. UTF-8 with a BOM.

  CFN Zone 3 routes 301-309   68 rows   every scheduled public ferry that
                                        calls at our 23 origin islands
  Villimalé ferry (VILI)     726 rows   Malé <-> Villimalé, both directions

Every one of the 23 origin islands has at least one row.

Columns
-------
  trip_id             One id per boat run. Legs of the same run share it, so
                      staying on board costs no transfer time.
  route_id, route_name  CFN route number (301-309) or VILI
  days                Days it runs, e.g. "Sat Sun Mon Tue Wed Thu", "Sun Wed"
  day_type            weekday (Sat-Thu), friday, as in BUILD_PLAN 6.1 step 5
  from, to            island_key (already normalised; all are in islands.csv
                      and island_names.csv)
  depart, arrive      HH:MM, local time
  dep_min, arr_min    Minutes from 00:00. A Villimalé arrival after midnight
                      is > 1440.
  departure_terminal, arrival_terminal
                      terminal_id for Greater Malé stops (T_MALE_NORTH,
                      T_MALE_WEST, T_HULHUMALE, T_VILLIMALE); blank elsewhere
  operator, mode      MTCC/RTL, ferry
  estimated           no = times printed in the schedule; yes = generated
  terminal_assumed    yes where the Malé jetty is not stated in the source
  source, notes

Sources
-------
- MTCC/RTL "CFN All ferry schedule", effective 1 Aug 2026, Zone 3 section.
- MTCC/RTL Villimalé ferry schedule 2026 V1, effective 21 Mar 2026.

Assumptions and things to check
-------------------------------
1. Malé jetty: the CFN schedule says "Male'" but not which jetty. All Malé
   stops on routes 303, 305-309 use T_MALE_NORTH (Jetty NO5) and are marked
   terminal_assumed = yes. ACCEPTED by the team (23 Oct); list it on the
   limits slide.
2. Route 307, Sat/Mon/Wed: the English text names the 11:40 stop "Male'",
   the Dhivehi text says Hulhumalé, and Malé follows at 12:15. Taken as
   Hulhumalé.
3. Stops outside the project (Himandhoo, Maalhos, Feridhoo, Mandhoo,
   Kunburudhoo, Fenfushi, Maamigili, Dhidhdhoo, Rakeedhoo) are left out and
   the legs either side are merged, so every name resolves. Route 310
   (Feridhoo - Mahibadhoo) only touches one project island, so it has no rows.
4. No CFN Zone 3 service on Fridays. Several routes run only on some days
   (303, 305, 306, 307). A single "weekday" day_type mixes those days, so
   pick a day (see the note below) or filter on `days`.
5. Villimalé ferry: departures generated from the published frequency
   bands (every 5-15 min by day, 30-60 min at night, Friday prayer break
   12:00-13:30). Crossing time is not published; 8 min, the team's figure. Same
   pattern assumed both ways. Malé side taken as T_MALE_WEST.
6. No fares in the schedules.

Note for the build (BUILD_PLAN 6.1 step 5)
------------------------------------------
Because routes alternate by day, "weekday" should mean one chosen day
rather than all of Sat-Thu merged. Suggested: add a DAY setting in
config.py and keep rows whose `days` contains it. Boats towards Malé:
  AA (303)          Sun, Wed
  ADh (305)         Sun, Tue, Thu
  V (306)           Sat, Mon, Wed
  K Kaashidhoo/Gaafaru (307)  Sat, Mon, Wed
  K north (308) and south (309)  every day except Friday
DECIDED (23 Oct): build for Wednesday, DAY = "Wed". Only ADh lacks a
Malé-bound boat that day; say so on the limits slide. No day has all of
them, which is itself a finding worth a slide. Friday has only
the Villimalé ferry. The +1440 "next day" copy should use the next
day's rows, not the same day's.
